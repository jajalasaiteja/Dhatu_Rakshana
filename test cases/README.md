# Dhatu Rakshana - Defect Test Cases Dataset Sample

This directory contains **40 representative test images** (10 for each of the 4 primary coating defect categories):
- `inclusions/` (10 images)
- `pinholes/` (10 images)
- `scratches/` (10 images)
- `contaminants/` (10 images)

Sourced directly from:
1. **Zenodo Subsea Marine Coating Dataset** (`data_set/CoatingDet_v2/CoatingDet_v2/`)
2. **Roboflow Thin-Film Defect Dataset** (`data_set/defect_detection_v43/`)

See `manifest.csv` in this folder for the exact source path, resolution, and file size of each test specimen.
